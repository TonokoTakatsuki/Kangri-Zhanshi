## 文件结构

每册一个文件夹，以「三位册号 + 篇名」命名（篇名取自原书版心）。文件夹内的文件沿用扫描源文件名：

```
054 桂南會戰/
├── 54.txt            纯文本（UTF-8，带 BOM，记事本可直接打开）
├── 54.md             同样的内容，带章节标题层级（Markdown）
└── figures/          图表页的彩色扫描图
    └── 54_p0012.jpg  p0012 是扫描文件中的页序，不是原书页码
```

## 制作方式与已知问题

- **来源**：djvu 扫描本（第 89 册为 PDF 扫描本）
- **识别**：使用 OvisOCR2 模型在本地识别；自动删除版心（书名、篇名、页码），按版面几何与标点重建段落，跨页的段落自动接续
- **图表页未识别**：竖排图表的 OCR 精度很差，因此图表页不做识别，只把彩色扫描图存入各册 `figures/`（共 3,645 张，其中 222 张为图文混排页——这类页面只识别正文部分，图表部分同样只存图）
