# 抗日戰史（OCR 文字）

《抗日戰史》全套 101 冊，中華民國國防部史政編譯局編纂，民國五十五年（1966 年）5 月由國防部史政編譯局出版。原書為直排繁體。

本儲存庫收錄全套 101 冊的 **OCR 文字**（已按原書目錄整理章節結構），以及書中圖表頁的彩色掃描圖。

> [!WARNING]
> **本儲存庫的文字以 OCR 自動辨識為底，大部分冊未經逐字校對**（各冊校對程度見下文「製作方式」），仍可能有錯字、漏字、衍字、標點錯誤等問題。引用時請以原書為準。

## 著作權狀態

本書由中華民國國防部史政編譯局編纂，於民國 55 年 5 月由國防部史政編譯局出版。本作品現時在大中華兩岸地區因著作權保護期屆滿而處於公有領域。

根據《中華人民共和國著作權法》第二十三條第二款（2020 年修正前為第二十一條第二款；司法管轄區為中國大陸，不包括香港和澳門）和中華民國《著作權法》第三十三條（目前司法管轄區為臺澎金馬地區），所有著作權持有者為法人的作品，在首次發表 50 年後，或者從創作之日起 50 年未發表，即進入公有領域。其他適用作品則在作者死亡後 50 年進入公有領域。

本書於 1966 年首次發表，保護期已於 2016 年 12 月 31 日屆滿。

## 內容

全書按篇編排：

- **第 1 冊**：總目錄
- **第 2–10 冊**：戰前世界大勢及中日國勢概況、戰爭起因、全戰爭經過概要
- **第 11–88 冊**：歷次作戰與會戰——自榆關及熱河作戰、一二八淞滬作戰、七七事變與平津作戰，經徐州、淞滬、太原、武漢諸會戰，三次長沙會戰，至豫中、長衡、桂柳、湘西會戰及南戰場追擊
- **第 89–98 冊**：游擊戰（魯蘇、冀察、晉綏及各地）
- **第 99–101 冊**：受降、復員

## 檔案結構

每冊一個資料夾，以「三位冊號 + 篇名」命名（篇名取自原書版心）。主檔沿用掃描來源檔名，例如第 54 冊：

```
054 桂南會戰/
├── 54.md             結構整理版：按原書目錄分級的章節標題，圖表頁以圖片嵌入（Markdown）
├── 54.txt            同一內容的純文字（UTF-8，含 BOM，記事本可直接開啟）
├── 54.wiki           同一內容的維基文本（純 Wikitext，可貼入維基文庫）
├── 待核清单.md        本冊尚未解決的項目：未轉錄的圖表、存疑字、空白頁判定等
└── figures/          圖表頁的彩色掃描圖（已去除「淞滬」浮水印）
    └── 54_p0012.jpg  p0012 為掃描檔中的頁序，並非原書頁碼
```

第 5 冊另有人工校對稿 `05_已校對.md`。

## 製作方式與已知問題

- **來源**：DjVu 掃描本（第 89 冊為 PDF 掃描本）
- **辨識**：以 OvisOCR2 模型於本機辨識
- **結構整理**：依各冊分目錄及第 1 冊總目錄定出篇、章、節、款、項、目各級標題；刪除版心（書名、篇名、頁碼）及混入正文的頁邊殘字；跨頁斷開的句子逐對判定後接續
- **校對程度**：
  - 第 2 冊：人工逐頁校訂
  - 第 3–16 冊及第 101 冊：另以 HunyuanOCR 全文重新辨識，逐字比對兩稿，分歧處判定後改正
  - 其餘各冊：只改正上述比對中確認的同類誤識（如「南濤路」→「南潯路」），未逐字校對
  - 全部各冊：待核清單中的文字疑點、跨頁斷句及空白頁約 420 條已逐條看原圖核查；原 OCR 漏識的頁面已據 HunyuanOCR 補錄，並看圖核對
- **用字**：原書字形（旣、卽、爲、僞等）照錄，原書本身的錯字與日期矛盾亦照原印保留；但 OCR 有時把「囘」「欵」等異體辨識成通行字，尚未全面復原
- **圖表不轉錄**：直排圖表、地圖、編制表只保留彩色掃描圖（共 3,450 張，已去除浮水印），圖中文字未轉錄
- 各冊仍待解決的項目列於該冊 `待核清单.md`
