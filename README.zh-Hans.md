## 文件结构

每册一个文件夹，以「三位册号 + 篇名」命名（文件夹名沿用原书版心的繁体篇名）。文件夹内的文件沿用扫描源文件名：

```
<册号> <篇名>/
├── <源文件名>.txt            纯文本（UTF-8，带 BOM，记事本可直接打开）
├── <源文件名>.md             同样的内容，带章节标题层级，图表页以图片嵌入（Markdown）
└── figures/                  图表页的彩色扫描图
    └── <源文件名>_p0012.jpg  p0012 是扫描文件中的页序，不是原书页码
```

## 制作方式与已知问题

- **来源**：DjVu 扫描本（第 89 册为 PDF 扫描本）
- **识别**：使用 OvisOCR2 模型在本地识别；自动删除版心（书名、篇名、页码），按版面几何与标点重建段落，跨页的段落自动接续
- **图表页未识别**：竖排图表的 OCR 精度很差，因此图表页不做识别，只把彩色扫描图存入各册 `figures/`（共 3,645 张，其中 222 张为图文混排页——这类页面只识别正文部分，图表部分同样只存图）
- **空白页**（含只有背面透墨的页）已跳过，共 654 页
- **识别失败、没有收入文字的页**（扫描文件页序）：
  - 第 69 册 浙赣会战：第 242 页
  - 第 72 册 缅北及滇西之作战：第 34、35、43、44、45、46 页
