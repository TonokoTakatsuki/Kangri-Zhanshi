- **第99–101冊**：降伏の受理、復員

## ファイル構成

各冊が1つのフォルダで、「3桁の冊番号 + 原題の篇名」という名前になっています。フォルダ内のファイル名はスキャン元のファイル名のままです。第54冊の例：

```
054 桂南會戰/
├── 54.txt            プレーンテキスト（UTF-8、BOM付き）
├── 54.md             同じ内容を章見出しの階層付きで（Markdown）
└── figures/          図表ページのカラースキャン画像
    └── 54_p0012.jpg  p0012 はスキャンファイル内のページ順で、原書の頁番号ではない
```

## 作成方法と既知の問題

- **底本**：DjVu 形式のスキャン（第89冊のみ PDF 形式のスキャン）
- **認識**：OvisOCR2 モデルによりローカルで認識。版心（書名・篇名・頁番号）を自動で除去し、版面の配置と句読点から段落を復元、ページをまたぐ段落は自動で接続
- **図表ページは未認識**：縦組みの図表は OCR の精度が低いため認識の対象外とし、カラースキャン画像のみを各冊の `figures/` に保存（計3,645枚。うち222枚は図と本文が混在するページで、本文部分のみを認識し、図表部分は画像のみ保存）
- **白紙ページ**（裏写りのみのページを含む）は除外、計654ページ
- **認識に失敗し、テキストが収録されていないページ**（スキャンファイル内のページ順）：
  - 第69冊 浙贛会戦：242ページ
  - 第72冊 北ビルマおよび雲南西部の作戦：34、35、43、44、45、46ページ
