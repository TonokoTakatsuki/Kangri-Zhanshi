## 著作権について

本書は中華民国国防部史政編訳局が編纂し、民国55年5月に同局から刊行されたものです。本作品は著作権の保護期間が満了しているため、現在、中国大陸および台湾においてパブリックドメインとなっています。

『中華人民共和国著作権法』第23条第2項（2020年改正前は第21条第2項。法域は中国大陸で、香港・マカオを除く）および中華民国『著作権法』第33条（現在の法域は台湾・澎湖・金門・馬祖）によれば、著作権者が法人である著作物は、最初の公表から50年を経過したとき、または創作から50年以内に公表されなかったときに、パブリックドメインとなります。その他の著作物は、著作者の死後50年でパブリックドメインとなります。

本書は1966年に初めて公表されており、保護期間は2016年12月31日に満了しています。

- **第99–101冊**：降伏の受理、復員

## ファイル構成

各冊が1つのフォルダで、「3桁の冊番号 + 原題の篇名」という名前になっています。主ファイルの名前はスキャン元のファイル名のままです。第54冊の例：

```
054 桂南會戰/
├── 54.md             構造整理版：原書の目次に沿った階層付きの章見出し、図表ページは画像として埋め込み（Markdown）
├── 54.txt            同じ内容のプレーンテキスト（UTF-8、BOM付き）
├── 54.wiki           同じ内容のウィキテキスト（プレーンな Wikitext、ウィキソースに貼り付け可）
├── 待核清单.md        この冊の未解決事項：未転記の図表、疑わしい文字、白紙ページの判定など
└── figures/          図表ページのカラースキャン画像（「淞滬」の透かしを除去済み）
    └── 54_p0012.jpg  p0012 はスキャンファイル内のページ順で、原書の頁番号ではない
```

第5冊には人手による校正稿 `05_已校對.md` もあります。

## 作成方法と既知の問題

- **底本**：DjVu 形式のスキャン（第89冊のみ PDF 形式のスキャン）
- **認識**：OvisOCR2 モデルによりローカルで認識
- **構造整理**：各冊の分冊目次と第1冊の総目次から篇・章・節・款・項・目の見出し階層を決定。版心（書名・篇名・頁番号）と本文に紛れ込んだ欄外の残字を除去し、ページをまたいで切れた文は一組ずつ判定して接続
- **校正の程度**：
  - 第2冊：人手で全ページ校訂
  - 第3–16冊と第101冊：HunyuanOCR で全文を再認識し、二つの稿を一字ずつ照合、相違箇所を判定して修正
  - その他の冊：上記の照合で確認された同種の誤認識（「南濤路」→「南潯路」など）のみ修正、一字ずつの校正は未実施
  - 全冊：要確認リストの文字の疑問点・ページまたぎの文・白紙ページ約420件を原画像で一件ずつ確認。元の OCR が取りこぼしたページは HunyuanOCR で補い、画像と照合済み
- **字体**：原書の字形（旣・卽・爲・僞など）はそのまま収録し、原書自体の誤植や日付の矛盾も原文どおりに残す。ただし OCR が「囘」「欵」などの異体字を通用字として認識した箇所があり、全面的な復元はまだ行っていない
- **図表は転記しない**：縦組みの図表・地図・編制表はカラースキャン画像のみを保存（計3,450枚、透かし除去済み）。図中の文字は未転記
- 各冊の未解決事項はその冊の `待核清单.md` に記載
